# Gen-AI

Generative-AI projects.

| Project | Description |
|---|---|
| [rag-telecom-chatbot](rag-telecom-chatbot/) | A Retrieval-Augmented Generation customer-care assistant for a mobile operator. Answers Tier-1 support questions grounded in a FAQ, resolved support tickets, and PDF user guides — never from the model's own knowledge. Python · LangChain · ChromaDB · Streamlit. |
| [osa-copilot](osa-copilot/) | An OSA Root-Cause Copilot for consumer-health retail execution. Flags at-risk store-SKUs, ranks them by estimated lost sales, diagnoses root causes from a fixed cause list with cited evidence and a "Needs investigation" gate, and drafts playbook actions for manager approval. Python · LangChain · Groq · Streamlit. |

Each project has its own README with setup and run instructions.
